# Sanitation acting

Plant-pot emergency use has an original short privacy glance, a shallow knee brace and a relieved exhale. The existing actor root and action controller retain movement ownership. A visual leg solver keeps the original ankle destinations planted as the torso leans from its hips. Clothing and released production geometry are unchanged.

An accepted accident event requests a two-second downcast, hand-to-temple reaction. It runs only while stationary with no active action or held/fading hand props. Walking, cooking, serving, eating, mopping and other actions discard the gesture; it cannot replay late after the activity ends. Pause freezes its animation clock. The reaction is presentation only and does not create an action, alter a route, charge funds or change food custody. Its brief visual timer is not saved.

Run `TMPDIR="$PWD/dist/test-work" python tests/run_sanitation_acting.py --source "$PWD"` after creating that temporary directory. The runner copies the runtime into a private project, removes editor/MCP autoloads, sets both XDG and JustLife data paths before startup, and records input hashes and results. `--capture` opens a temporary game window and records actual frame images, so coordinate its use with other rendering work. The existing `tests/run_sanitation.py` verifies sanitation saves, actual paid cooking/carrying and neighborhood travel.

The acting test covers released default/broad adult bodies and child/elder controls, actual pot approach and cancellation with a later queue item, planted contacts, pause, genuine accident callbacks and interruption by movement, paid cooking, real dish custody and cleanup. Its mop-hand distance is diagnostic: an additional absolute-contact probe found that the released lower mop grip is already beyond the arm's reach in one broad-frame stove-puddle case (about 0.337 m). The unchanged baseline reproduces this; this acting change does not repair that separate alignment issue.

This is a bounded acting improvement. It does not establish a complete character-animation or full-game 10/10 rating. At high simulation speed, the short action can finish before every visual beat is shown.
