Initial autonomous choices and explicit player instructions retain their existing behavior; standalone simulations retain their previous policy without a provider.

An eligible ordinary floor activity approach briefly retains its original path when the next physical step is blocked. This gives the existing household give-way selector an opportunity before another detour is installed. The original step moves immediately if it becomes clear. No runtime change followed from that wording correction.

Retry observations are derived, so the saved format does not change. Pause freezes them.
