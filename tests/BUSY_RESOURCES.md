Run `python tests/run_busy_resources.py` from an integrated source tree. It creates a fresh private Linux project under `dist/test-work/busy-resource-check-*`, disables plugin/autoload entries only in that copy, and uses private XDG, TMPDIR and JustLife save paths. It never reads or overwrites a player's home saves.

The initial fixture was earned through actual four-person Creator, move-in, paid Build and ordinary autonomy; it pauses at Casey's blocked approach to Rowan's occupied bed. The runner produces its own public waiting and two-person queue saves before fresh-process continuation. Natural flows use public controls and ordinary `.05` process calls with one yielded frame. Negative component cases are separately declared. No renderer or native input is required.

The checks cover real nearby queue admission, delayed autonomous recovery, later player instructions, both FIFO turns, paused/fresh reconstruction, unrelated Build preservation, actual target move/sale, and supported geometry/ownership refusals. They do not assert completion of a full night's sleep or a successful multi-day household routine.

Each phase retains a log, receipt, report and input/save hashes. Any warning, script error, source/copy drift, overwritten existing save/index or report mismatch fails the wrapper. `--prepare-only` validates the private copy without launching Godot. Required dependencies are the existing `test_courtesy.gd`, `test_playthrough.gd`, `test_public_twofloor.gd`, their UIDs and the production manifest. Add this test and its UID/fixture/runner to the maintained test guide; no new production resource path is introduced by this main-only change.
